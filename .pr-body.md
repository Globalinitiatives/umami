## What

Rebrand the entire GMAnalytics deployment surface from "Umami" to "GMAnalytics" — tracker script name, logo, favicon, session storage keys, API headers, localStorage keys, DOM attributes, and all brand text.

This is a branding-only change. No behaviour, schema, or API contract changes.

## Tracker script (the runtime file served to website visitors)

- `src/tracker/index.ts` — `window.umami` → `window.gmanalytics`, type `UmamiTracker` → `GmanalyticsTracker`, localStorage key `umami.disabled` → `gmanalytics.disabled`, `data-umami-event-*` → `data-gmanalytics-event-*`, `x-umami-*` headers → `x-gmanalytics-*`, all JSDoc examples use `gmanalytics.*`
- `src/tracker/index.d.ts` — global augmentation `gmanalytics`, all examples use `gmanalytics.*`
- `rollup.tracker.config.js` — Rollup replace token `UMAMI` → `GMANALYTICS` at build time (produces `window.gmanalytics` in the minified bundle), output filename `public/script.js` → `public/gmanalytics.js`
- `scripts/update-tracker.js` — minified bundle path `public/script.js` → `public/gmanalytics.js`
- `docker/proxy.ts` — proxy tracker path `/script.js` → `/gmanalytics.js`
- `src/app/(main)/App.tsx`, `WebsiteTrackingCode.tsx`, `TestConsolePage.tsx` — embed snippet src `script.js` → `gmanalytics.js`
- `.github/workflows/deploy.yml` — env `TRACKER_SCRIPT_NAME=gmanalytics.js`

## API headers (the HTTP headers the tracker sends to the server)

- `src/lib/constants.ts` — `SHARE_TOKEN_HEADER`, `SHARE_CONTEXT_HEADER`, `CACHE_HEADER` = `x-gmanalytics-*`

- `src/lib/detect.ts` — `x-gmanalytics-client-country/region/city` headers
- `src/lib/ip.ts` — `x-gmanalytics-client-ip` custom header (cloud mode)
- `src/recorder/index.js` — recorder sends `x-gmanalytics-cache`

- `src/openapi/` — extension attributes `x-gmanalytics-audience/contract/source`, security scheme header names, OpenAPI `description` text, `README.md` docs
