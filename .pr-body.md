## What

Adds `.github/workflows/deploy.yml` for deploying Umami via self-hosted runner (`hercule` / `umami`).

## How it works

- Triggers on push to **master** or manual `workflow_dispatch`
- Builds `gmanalytics:latest` from the root `Dockerfile`
- Creates isolated network `gmanalytics_network` for internal comms (app ↔ db)
- Runs PostgreSQL as `gmanalytics-db` on `gmanalytics_network` only
- Runs Umami as `gmanalytics` on `gmanalytics_network` + connected to `npm_default` for reverse proxy access
- **No host port exposure** — health check uses `docker exec` internally
- Prunes old images after deploy
- Vercel auto-deploys disabled (`deploymentEnabled: false`)

## Secrets required

| Secret | Value |
|---|---|
| `POSTGRES_PASSWORD` | PostgreSQL password |
| `APP_SECRET` | Umami app secret |
| `TWO_FACTOR_ENCRYPTION_KEY` | 64-char hex (2FA encryption key) |
